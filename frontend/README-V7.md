# Pragati University AR / VR Club — V7 Advanced Planet

This version updates only the 3D hero system:
- `src/3d/EnergyCore.jsx`
- `src/3d/HolographicRings.jsx`
- `src/3d/Scene.jsx`

The planet uses a sparse geometric shell, surface nodes, crystalline energy core, subtle orbital arcs and controlled bloom. Mouse movement rotates the planet without translating it across the page.

Run:
```bash
npm install
npm run build
npm run preview
```
