# Pragati University AR/VR Club — V5 Immersive

V5 keeps the V4 full-page immersive content system while refining the hero into a darker, cleaner holographic interface.

## Hero changes
- Explicit black WebGL clear color; prevents the washed-out/white hero seen in V4.
- One sparse icosahedral shell instead of multiple dense wireframe layers.
- Surface energy particles add depth without extra grid lines.
- Only two orbital paths.
- Reduced bloom for sharper contrast.
- Globe remains fixed in position and rotates physically with pointer movement.

## Run
```bash
npm install
npm run dev
```
