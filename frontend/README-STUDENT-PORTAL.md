# Pragati AR/VR Club — Student Portal UI

## Routes
- `/` — existing public AR/VR Club website
- `/student` — immersive Student Portal dashboard

## Student Portal UI coverage
- Student profile
- Upcoming events + registration state
- Attendance / heatmap
- Club points and progression
- Badges / achievements
- Leaderboard
- Teams-ready navigation
- Calendar
- Certificates-ready navigation
- Notifications
- Settings / public-site navigation

This release is UI-first. Backend actions can be connected to the existing backend later without redesigning the portal.
