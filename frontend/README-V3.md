# Pragati University AR / VR Club — V3 Advanced Hero

This version keeps the V2 page layout, typography, navigation and sections, while refining only the 3D hero visual.

### Visual changes
- Removed the dense multi-layer latitude/longitude wireframe look.
- Replaced it with a sparse triangular holographic shell.
- Added a soft translucent atmospheric body for depth.
- Reduced outer orbital rings to two subtle rings.
- Reduced broken orbital arcs to three restrained arcs.
- Reduced interactive satellites to 5 mobile / 8 desktop nodes.
- Added a layered glowing energy core.
- Preserved mouse-controlled physical rotation and slow autonomous rotation.
- Preserved the planet's fixed position in the hero composition.

### Run
```bash
npm install
npm run dev
```

For a production check:
```bash
npm run build
npm run preview
```

No other V2 sections were intentionally redesigned.
