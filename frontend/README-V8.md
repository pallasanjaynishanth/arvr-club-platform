# Pragati University AR / VR Club — V8 Advanced Planet

V8 upgrades only the Three.js hero planet system while preserving the existing site structure and content.

## Updated 3D files

- `src/3d/EnergyCore.jsx` — cinematic multi-layer holographic planet, crystalline energy engine, surface nodes, orbital energy particles and segmented arcs.
- `src/3d/HolographicRings.jsx` — refined three-layer outer orbital system.
- `src/3d/Scene.jsx` — tuned placement, lighting and bloom for a deeper cinematic presentation.

## Run

```bash
npm install
npm run build
npm run preview
```

Or use `npm run dev` for development.
